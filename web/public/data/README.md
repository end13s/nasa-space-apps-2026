# web/public/data/ - the bundle the browser loads

Generated by `engine/pack_web.py`; never edit these files by hand.

**Current contents: real data.** The Earth grid is ETOPO 2022 + WorldClim 2.1
(`pipeline/earth/fallback_grid.py`), the Moon and Mars targets come from
`contract/targets.json` built at the matched 1855 m terrain baseline, and
`earth_meta.json` records `"synthetic_grid": false`.

| file | what |
|---|---|
| `earth_features.bin` | Uint8 `[cells x features]`, 255 = missing |
| `earth_index.bin` | Uint32 cell id per row |
| `earth_meta.json` | feature table, quantization bounds, sigma, grid geometry |
| `targets.json` | Moon and Mars fingerprints with evidence grades |
| `transfer_rules.json` | transferable / conditional / not transferable, per body |
| `validation.json` | validation and ablation results for the Validation tab |
| `known_analogs.json` | documented analog sites, shown as grey pins |
| `deep_dives/` | Discoveries-tab cards |

The folder is ignored by git, and the real bundle is committed deliberately with
`git add -f web/public/data`, so a stray synthetic rebuild never lands by accident.
Rebuild instructions are in the top-level README.
